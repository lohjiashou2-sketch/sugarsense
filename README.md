# Sugarsense

## Project Overview
This project is an integrated web-based system designed to predict an individual’s risk of diabetes and provide personalized diet recommendations using machine learning techniques. The system aims to support early risk awareness and promote healthier lifestyle choices through data-driven insights.

---

## Objectives
- To develop a machine learning-based model for diabetes risk prediction
- To compare multiple machine learning algorithms and identify the best-performing model
- To design a personalized diet recommendation module based on user profiles
- To deploy the system as a functional web application for real-world usability

---

## Methodology

### 1. Data Preprocessing
- Data cleaning and handling of missing values
- Feature scaling and normalization
- Exploratory data analysis (EDA) to identify important features

### 2. Machine Learning Models
The following models were implemented and evaluated:
- Gradient Boosting (Best-performing model)
- Support Vector Machine (SVM)
- Random Forest
- XGBoost
- Logistic Regression

Model performance was evaluated using appropriate classification metrics such as accuracy, precision, recall, and F1-score.

---

## Personalized Diet Recommendation Module
- Implemented using **K-Nearest Neighbors (KNN)**
- Provides personalized diet recommendations based on users preferences
- Considers health-related attributes to generate personalized suggestions
